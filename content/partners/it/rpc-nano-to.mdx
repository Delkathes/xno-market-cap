# RPC.Nano.To: Infrastruttura per sviluppatori per Nano

RPC.Nano.To è l'infrastruttura di pagamento completa per la rete di criptovalute Nano. Costruisci applicazioni Nano pronte per la produzione con nodi RPC distribuiti globalmente, proof of work alimentata da GPU e API progettate per gli sviluppatori — dalla tua prima chiamata RPC alla tua miliardesima transazione.

## Perché scegliere RPC.Nano.To?

### Infrastruttura globale ultrarapida

Accedi a oltre 65 nodi Nano distribuiti su 20 regioni che coprono Nord America, Europa, Asia, Africa e Caraibi. Tempi di risposta inferiori a un secondo garantiscono che la tua applicazione fornisca transazioni Nano istantanee ovunque nel mondo.

### Generazione proof of work GPU

Smetti di preoccuparti del sovraccarico computazionale. RPC.Nano.To fornisce cluster GPU dedicati che generano la proof of work per le tue transazioni, così la tua applicazione rimane leggera e reattiva.

### API progettate per sviluppatori

API REST pulite e ben documentate con supporto multi-linguaggio. Che tu stia costruendo in Node.js, JavaScript browser, Python, PHP o usando cURL, la piattaforma fornisce SDK ed esempi chiari per iniziare in pochi minuti.

## Esempio di codice: Inviare Nano in 5 comandi

```bash
# Installare CLI globalmente
npm install -g @nano/wallet

# Impostare la chiave API
export NANO_RPC_KEY=TUA_CHIAVE_API

# Generare wallet
nano-wallet generate --secret miapassword

# Richiedere Nano di test dal faucet
nano-wallet faucet --secret miapassword

# Ricevere blocchi in sospeso
nano-wallet receive --secret miapassword

# Verificare saldo
nano-wallet balance --secret miapassword

# Inviare Nano
nano-wallet send nano_3destinatario... 0.1 --secret miapassword
```
