RPC.Nano.To è un livello ospitato di RPC e pagamenti per Nano: 65 nodi in 20 regioni, proof of work su GPU e API REST con SDK per i linguaggi che gli sviluppatori usano davvero. È pensato per chi vuole un'integrazione Nano funzionante senza gestire un nodo.

## Perché RPC.Nano.To

### Nodi in 20 regioni

Oltre 65 nodi Nano distribuiti in 20 regioni tra Nord America, Europa, Asia, Africa e Caraibi. Le risposte arrivano sotto il secondo, ed è questo che fa sembrare istantaneo un flusso di pagamento.

### Proof of work fuori dal tuo server

Cluster GPU dedicati generano la proof of work per le tue transazioni, così l'applicazione resta leggera e reattiva invece di portarsi il carico computazionale.

### API e SDK

Endpoint REST con documentazione ed esempi per Node.js, JavaScript nel browser, Python, PHP e cURL. Gli esempi sono abbastanza brevi per partire in pochi minuti.

## Funzioni principali

- **Rete di nodi globale**: 65 nodi in 20 regioni, per disponibilità e latenza bassa
- **Chiamate RPC**: un piano gratuito che cresce fino a richieste illimitate con l'app
- **Proof of work**: i cluster GPU fanno il calcolo, la tua app no
- **Checkout**: flussi di pagamento con webhook, metadati e tracciamento delle conferme
- **WebSocket**: monitoraggio delle transazioni e conferme dei blocchi in tempo reale
- **CLI**: gestione di portafogli e transazioni dal terminale
- **Faucet**: 0,001 NANO per test e sviluppo

## Perché Nano

- **Zero commissioni di transazione**: applicazioni di micropagamento senza l'economia delle commissioni
- **Finalità sotto il secondo**: le transazioni si confermano in meno di un secondo, ed è ciò di cui hanno bisogno i flussi di pagamento in tempo reale
- **Infrastruttura senza commissioni**: paghi l'accesso API e la proof of work, non la singola transazione
- **Accesso aperto**: pagamenti da chiunque, ovunque, senza intermediari

## Come iniziare

1. **Ottieni una chiave API gratuita**: iscriviti su rpc.nano.to per 50.000 chiamate RPC al giorno più 100 generazioni di proof of work
2. **Installa la CLI**: esegui `npm install -g @nano/wallet` per gestire portafogli e transazioni dal terminale
3. **Genera un portafoglio**: crea un portafoglio cifrato in locale con `nano-wallet generate --secret yourpassword`
4. **Richiedi Nano di test**: usa il faucet per ricevere 0,001 NANO per sviluppo e test
5. **Inizia a costruire**: fai la prima chiamata RPC, oppure aggiungi l'SDK Node.js o browser alla tua applicazione

## Esempio di codice: inviare Nano in pochi comandi

```bash
# Installare CLI globalmente
npm install -g @nano/wallet

# Impostare la chiave API
export NANO_RPC_KEY=YOUR_API_KEY

# Generare portafoglio
nano-wallet generate --secret mypassword

# Richiedere Nano di test dal faucet
nano-wallet faucet --secret mypassword

# Ricevere blocchi in sospeso
nano-wallet receive --secret mypassword

# Verificare saldo
nano-wallet balance --secret mypassword

# Inviare Nano
nano-wallet send nano_3recipient... 0.1 --secret mypassword
```
