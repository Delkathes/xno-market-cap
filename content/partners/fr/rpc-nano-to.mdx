RPC.Nano.To est une couche RPC et paiement hébergée pour Nano : 65 nœuds dans 20 régions, preuve de travail sur GPU et API REST avec des SDK pour les langages que les développeurs utilisent vraiment. Le service vise les équipes qui veulent une intégration Nano fonctionnelle sans faire tourner de nœud.

## Pourquoi RPC.Nano.To

### Des nœuds dans 20 régions

Plus de 65 nœuds Nano répartis dans 20 régions : Amérique du Nord, Europe, Asie, Afrique et Caraïbes. Les requêtes reviennent en moins d'une seconde, ce qui garde un flux de paiement instantané.

### Preuve de travail, hors de votre serveur

Des clusters GPU dédiés génèrent la preuve de travail de vos transactions ; l'application reste légère et réactive au lieu de porter le calcul elle-même.

### API et SDK

Des points de terminaison REST documentés, avec des exemples en Node.js, JavaScript côté navigateur, Python, PHP et cURL. Les exemples sont assez courts pour démarrer en quelques minutes.

- **Réseau de nœuds mondial** : 65 nœuds dans 20 régions, pour la disponibilité et une faible latence

- **Infrastructure sans frais** : vous payez l'accès API et la preuve de travail, pas chaque transaction

## Démarrer

1. **Obtenez une clé API gratuite** : inscrivez-vous sur rpc.nano.to pour 50 000 appels RPC par jour et 100 générations de preuve de travail
2. **Installez le CLI** : exécutez `npm install -g @nano/wallet` pour gérer portefeuilles et transactions depuis votre terminal
3. **Générez un portefeuille** : créez un portefeuille chiffré en local avec `nano-wallet generate --secret yourpassword`
4. **Réclamez des Nano de test** : utilisez le faucet pour recevoir 0,001 NANO pour le développement et les tests
5. **Commencez à construire** : faites un premier appel RPC, ou ajoutez le SDK Node.js ou navigateur à votre application

## Exemple de code : envoyer du Nano en cinq commandes

```bash
# Installer le CLI globalement
npm install -g @nano/wallet

# Définir votre clé API
export NANO_RPC_KEY=YOUR_API_KEY

# Générer un portefeuille
nano-wallet generate --secret mypassword

# Réclamer du Nano de test depuis le faucet
nano-wallet faucet --secret mypassword

# Recevoir les blocs en attente
nano-wallet receive --secret mypassword

# Vérifier le solde
nano-wallet balance --secret mypassword

# Envoyer du Nano
nano-wallet send nano_3recipient... 0.1 --secret mypassword
```
