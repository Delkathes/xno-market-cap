# RPC.Nano.To : Infrastructure développeur pour Nano

RPC.Nano.To est l'infrastructure de paiement complète pour le réseau de cryptomonnaie Nano. Créez des applications Nano prêtes pour la production avec des nœuds RPC distribués mondialement, une preuve de travail alimentée par GPU et des APIs axées développeur — de votre premier appel RPC à votre milliardième transaction.

## Pourquoi choisir RPC.Nano.To ?

### Infrastructure mondiale ultra-rapide

Accédez à plus de 65 nœuds Nano répartis sur 20 régions couvrant l'Amérique du Nord, l'Europe, l'Asie, l'Afrique et les Caraïbes. Des temps de réponse inférieurs à la seconde garantissent que votre application effectue des transactions Nano instantanées partout dans le monde.

### Génération de preuve de travail GPU

Arrêtez de vous soucier de la surcharge computationnelle. RPC.Nano.To fournit des clusters GPU dédiés qui génèrent la preuve de travail pour vos transactions, afin que votre application reste légère et réactive.

### APIs axées développeur

APIs REST propres et bien documentées avec support multi-langages. Que vous construisiez en Node.js, JavaScript navigateur, Python, PHP ou utilisiez cURL, la plateforme fournit des SDKs et des exemples clairs pour démarrer en quelques minutes.

## Fonctionnalités principales

- **Réseau de nœuds mondial** : 65 nœuds sur 20 régions assurant une disponibilité maximale et une latence minimale
- **Appels RPC illimités** : Évoluez du niveau gratuit aux requêtes illimitées au fur et à mesure que votre application grandit
- **Preuve de travail instantanée** : Les clusters GPU gèrent le travail computationnel pour que votre application n'ait pas à le faire

## Démarrer avec RPC.Nano.To

1. **Obtenez votre clé API gratuite** : Inscrivez-vous sur rpc.nano.to et recevez 50 000 appels RPC par jour plus 100 générations de preuve de travail
2. **Installez le CLI** : Exécutez `npm install -g @nano/wallet` pour gérer portefeuilles et transactions depuis votre terminal
3. **Générez un portefeuille** : Créez un portefeuille chiffré localement avec `nano-wallet generate --secret votremotdepasse`
4. **Réclamez du Nano de test** : Utilisez le faucet pour recevoir 0,001 NANO instantanément pour le développement et les tests
5. **Commencez à construire** : Effectuez votre premier appel RPC ou intégrez le SDK Node.js/Browser dans votre application

## Exemple de code : Envoyer du Nano en 5 commandes

```bash
# Installer le CLI globalement
npm install -g @nano/wallet

# Définir votre clé API
export NANO_RPC_KEY=VOTRE_CLE_API

# Générer un portefeuille
nano-wallet generate --secret monmotdepasse

# Réclamer du Nano de test depuis le faucet
nano-wallet faucet --secret monmotdepasse

# Recevoir les blocs en attente
nano-wallet receive --secret monmotdepasse

# Vérifier le solde
nano-wallet balance --secret monmotdepasse

# Envoyer du Nano
nano-wallet send nano_3destinataire... 0.1 --secret monmotdepasse
```
