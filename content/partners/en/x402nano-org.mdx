# x402nano.org: Feeless x402 Facilitator for Nano

x402nano.org is a facilitator for the [x402 protocol](https://www.x402.org/) on Nano. It helps developers and AI-ready apps verify and settle HTTP 402 payments with no account required.

## What It Does

The service sits between your app and the Nano network:

- **Verifies payment signatures** sent in `PAYMENT-SIGNATURE`
- **Settles payments on-chain** after validation
- Returns a payment response so your app can serve protected content

## Why Builders Use It

- **No signup required** to start integrating
- **Feeless Nano payments** for internet-native payment flows
- Works with **AI agent payment patterns** and machine-to-machine APIs
- Supports both **Next.js** and manual server integrations

## Quick Start

1. Set your facilitator URL to `https://x402nano.org/facilitator`
2. Integrate with `@x402/next` (middleware + route handlers) or `@x402/core`
3. Protect endpoints with HTTP 402 responses and settle successful payments

## Built for x402 Developers

According to its docs, x402nano.org provides a permissionless way to run x402 payment flows on Nano, including verify/settle endpoints and optional API key analytics.
