RPC.Nano.To es una capa alojada de RPC y pagos para Nano: 65 nodos en 20 regiones, prueba de trabajo con GPU y APIs REST con SDKs para los lenguajes que los desarrolladores usan. Está pensada para equipos que quieren una integración con Nano que funcione sin operar un nodo.

## ¿Por qué RPC.Nano.To?

### Nodos en 20 regiones

Más de 65 nodos Nano distribuidos en 20 regiones de Norteamérica, Europa, Asia, África y el Caribe. Las peticiones vuelven en menos de un segundo, que es lo que hace que un flujo de pago se sienta instantáneo.

### Prueba de trabajo fuera de tu servidor

Clústeres de GPU dedicados generan la prueba de trabajo de tus transacciones, así que la aplicación se mantiene ligera y responde sin cargar con el cálculo.

### APIs y SDKs

Endpoints REST con documentación y ejemplos en Node.js, JavaScript de navegador, Python, PHP y cURL. Los ejemplos son lo bastante cortos para empezar en minutos.

## Funciones principales

- **Red global de nodos**: 65 nodos en 20 regiones, para disponibilidad y baja latencia
- **Llamadas RPC**: un plan gratuito que escala a peticiones ilimitadas a medida que crece la aplicación
- **Prueba de trabajo**: los clústeres de GPU hacen el cálculo, no tu aplicación
- **Cobro**: flujos de pago con webhooks, metadatos y seguimiento de confirmaciones
- **WebSockets**: seguimiento de transacciones y confirmaciones de bloques en el momento en que ocurren
- **CLI**: gestión de carteras y transacciones desde la terminal
- **Faucet**: 0,001 NANO para pruebas y desarrollo

## Por qué Nano

- **Sin comisiones de transacción**: aplicaciones de micropagos sin que las comisiones entren en la ecuación
- **Finalidad en menos de un segundo**: las transacciones se confirman en menos de un segundo, lo que piden los flujos de pago en tiempo real
- **Infraestructura sin comisiones**: pagas por acceso a la API y prueba de trabajo, no por transacción
- **Acceso abierto**: pagos de cualquiera, en cualquier lugar, sin intermediarios

## Primeros pasos

1. **Obtén una clave API gratuita**: regístrate en rpc.nano.to y recibe 50.000 llamadas RPC al día más 100 generaciones de prueba de trabajo
2. **Instala el CLI**: ejecuta `npm install -g @nano/wallet` para gestionar carteras y transacciones desde la terminal
3. **Genera una cartera**: crea una cartera cifrada en local con `nano-wallet generate --secret yourpassword`
4. **Reclama Nano de prueba**: usa el faucet para recibir 0,001 NANO para desarrollo y pruebas
5. **Empieza a construir**: haz una primera llamada RPC o añade el SDK de Node.js o de navegador a tu aplicación

## Ejemplo de código: enviar Nano en cinco comandos

```bash
# Instalar CLI globalmente
npm install -g @nano/wallet

# Establecer tu clave API
export NANO_RPC_KEY=YOUR_API_KEY

# Generar billetera
nano-wallet generate --secret mypassword

# Reclamar Nano de prueba desde el faucet
nano-wallet faucet --secret mypassword

# Recibir bloques pendientes
nano-wallet receive --secret mypassword

# Verificar saldo
nano-wallet balance --secret mypassword

# Enviar Nano
nano-wallet send nano_3recipient... 0.1 --secret mypassword
```
