# RPC.Nano.To: Infraestructura de desarrollador para Nano

RPC.Nano.To es la infraestructura de pago completa para la red de criptomonedas Nano. Construye aplicaciones Nano listas para producción con nodos RPC distribuidos globalmente, prueba de trabajo impulsada por GPU y APIs diseñadas para desarrolladores — desde tu primera llamada RPC hasta tu billonésima transacción.

## ¿Por qué elegir RPC.Nano.To?

### Infraestructura global ultrarrápida

Accede a más de 65 nodos Nano distribuidos en 20 regiones que abarcan América del Norte, Europa, Asia, África y el Caribe. Tiempos de respuesta inferiores a un segundo garantizan que tu aplicación entregue transacciones Nano instantáneas en cualquier parte del mundo.

### Generación de prueba de trabajo GPU

Deja de preocuparte por la sobrecarga computacional. RPC.Nano.To proporciona clusters GPU dedicados que generan la prueba de trabajo para tus transacciones, para que tu aplicación permanezca ligera y receptiva.

### APIs diseñadas para desarrolladores

APIs REST limpias y bien documentadas con soporte multilenguaje. Ya sea que estés construyendo en Node.js, JavaScript de navegador, Python, PHP o usando cURL, la plataforma proporciona SDKs y ejemplos claros para comenzar en minutos.

## Características principales

- **Red de nodos global**: 65 nodos en 20 regiones asegurando máximo tiempo de actividad y mínima latencia
- **Llamadas RPC ilimitadas**: Escala desde el nivel gratuito a solicitudes ilimitadas a medida que tu aplicación crece
- **Prueba de trabajo instantánea**: Los clusters GPU manejan el trabajo computacional para que tu aplicación no tenga que hacerlo

- **Soporte WebSocket**: Monitoreo de transacciones en tiempo real y confirmaciones de bloques

## Empezar con RPC.Nano.To

1. **Obtén tu clave API gratuita**: Regístrate en rpc.nano.to y recibe 50,000 llamadas RPC por día más 100 generaciones de prueba de trabajo
2. **Instala el CLI**: Ejecuta `npm install -g @nano/wallet` para gestionar billeteras y transacciones desde tu terminal
3. **Genera una billetera**: Crea una billetera cifrada localmente con `nano-wallet generate --secret tucontraseña`
4. **Reclama Nano de prueba**: Usa el faucet para recibir 0.001 NANO instantáneamente para desarrollo y pruebas
5. **Empieza a construir**: Realiza tu primera llamada RPC o integra el SDK Node.js/Browser en tu aplicación

## Ejemplo de código: Enviar Nano en 5 comandos

```bash
# Instalar CLI globalmente
npm install -g @nano/wallet

# Establecer tu clave API
export NANO_RPC_KEY=TU_CLAVE_API

# Generar billetera
nano-wallet generate --secret micontraseña

# Reclamar Nano de prueba desde el faucet
nano-wallet faucet --secret micontraseña

# Recibir bloques pendientes
nano-wallet receive --secret micontraseña

# Verificar saldo
nano-wallet balance --secret micontraseña

# Enviar Nano
nano-wallet send nano_3destinatario... 0.1 --secret micontraseña
```
