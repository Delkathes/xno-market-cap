x402nano.org es un facilitador del [protocolo x402](https://www.x402.org/) sobre Nano. Verifica y liquida pagos HTTP 402 para desarrolladores y aplicaciones preparadas para IA, sin necesidad de cuenta.

## Qué hace

El servicio se coloca entre tu aplicación y la red Nano:

- **Verifica las firmas de pago** enviadas en `PAYMENT-SIGNATURE`
- **Liquida el pago en la cadena** después de validarlo
- Devuelve una respuesta de pago para que tu aplicación sirva el contenido protegido

## Por qué lo usan quienes construyen

- **Sin registro** para empezar a integrar
- **Pagos en Nano sin comisiones** para flujos de pago propios de internet
- Encaja con **patrones de pago de agentes de IA** y APIs de máquina a máquina
- Funciona con **Next.js** y también con integraciones manuales en el servidor

## Inicio rápido

1. Configura la URL del facilitador en `https://x402nano.org/facilitator`
2. Integra `@x402/next` (middleware y route handlers) o `@x402/core`
3. Protege los endpoints con respuestas HTTP 402 y liquida los pagos que se completen

## Pensado para desarrolladores de x402

Según su documentación, x402nano.org ofrece una forma sin permisos de ejecutar flujos de pago x402 en Nano, con endpoints de verify y settle y estadísticas opcionales mediante clave API.

- Documentación: [x402nano.org/docs](https://x402nano.org/docs)
- Sitio: [x402nano.org](https://x402nano.org/)
